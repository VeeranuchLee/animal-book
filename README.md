# Our Animal Book

An illustrated animal vocabulary atlas for children. Tap an animal and it moves and
says its name; tap its name and the page tells you how to spot it, what its family
words are, and which animals it is easy to mix up with.

**Live:** https://veeranuchlee.github.io/animal-book/

One room is published so far — `rainforest/`, sixteen animals.

Built from the private `children-games` repository, which is the source of truth.
Artwork, animation clips and the ambience bed are AI-generated for this project.
